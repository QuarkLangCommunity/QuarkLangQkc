# QuarkLang — Primitives, and Everything Derived From Them

**Status:** analysis and proposal. This document is *not* the standard. `spec/STANDARD.md` is the
owner's document and is untouched by this work; where this document proposes a change to the standard
it says so and leaves the ruling to the owner (§8).

**Analysed at:** `923784b` (tip of `main` when this document was written). The implementation moves;
every `file:line` reference is a claim about *that* revision and is marked as such.

**The owner's instruction this document answers:** *distil everything into a standard with very few
primitives — every feature should either be a primitive or be derived from the primitives by a stated
rule, instead of being enumerated as its own case.*

Conventions:

| Symbol | Meaning |
|---|---|
| ✔ | verified by reading or running the cited site |
| ⚠ | partially verified, or verified only for some cases |
| ✘ | not verified — marked **UNVERIFIED** rather than asserted |
| `P-k` | a proposed primitive (§4) |
| `D-k` | a derivation rule (§4) |
